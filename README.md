# F1 Stats

A data-focused Formula 1 statistics and tools website.

## Stack

- Next.js + TypeScript
- Tailwind CSS
- Static export for GitHub Pages
- Jolpica F1 API (planned data source)
- Python + GitHub Actions (planned automated data pipeline)

## Roadmap

- [x] Initial homepage
- [x] Driver standings
- [x] Constructor standings
- [x] Race results and weekend schedules
- [x] Qualifying and Sprint result tables
- [x] Driver head-to-head comparison
- [x] F1 weekend points calculator
- [x] Championship scenario simulator
- [x] Lap-time delta calculator
- [x] Pit-stop strategy calculator
- [x] Automated Jolpica data updates
- [x] Static pages for drivers, teams and races
- [x] English and Chinese interface support
