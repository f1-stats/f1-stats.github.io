# Circuit Images

The race calendar displays an image only when a matching file exists here.
Name files after the Jolpica `circuitId`, for example `shanghai.svg`.
Supported formats, in priority order: SVG, PNG, WebP, JPG, JPEG.

The included SVGs are by F1Laps, distributed under the MIT license in LICENSE:
https://github.com/f1laps/f1-track-vectors/tree/981ef8e7bc9cb98380602f65f9b7b7f2ba0fe5d9/f1_2020

These diagrams depict 2020 layouts. Known subsequently revised circuits
(Albert Park, Yas Marina, Barcelona and Singapore) are intentionally omitted.
Missing circuits can be added with correctly licensed, accurate diagrams.
The lookup is circuit-based, not season-based; diagrams do not reproduce every
historical layout change. Rebuild the static site after adding an image.
